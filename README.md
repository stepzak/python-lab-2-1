# Лабораторная работа 2.1

* **Цель:** Освоить duck typing и контрактное программирование на примере источников
задач.

* **Чему я научился:**
    - описание контрактов с помощью **typing.Protocol**
    - работа с итераторами с помощью **yield**
## Струкутра проекта: 

* **src/sources** - примеры источников ззадач
* **src/task_receiver** - контракт взаимодействия
* **src/utils** - утилиты(в данном случае декоратор *@strict_annotations*, поднимающий исключение в runtime в случае несовпадения типов аргументов)
* **src/consumer.py** - функция, принимающая на вход источник задач
